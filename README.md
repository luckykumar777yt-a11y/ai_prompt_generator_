✦ PromptGen - AI Prompt Generator
A modern, responsive, and beginner-friendly web application built with HTML, CSS, and JavaScript to help users create, format, and structure clear AI prompts quickly.

🚀 Features
Role & Task Builder: Define the AI persona and the primary task clearly.

Context & Constraints: Add background details and specific limitations or rules.

Output Format Selection: Choose from bullet points, step-by-step guides, tables, code blocks, and more.

One-Click Generation: Instantly builds a structured, professional prompt.

Copy & Clear Controls: Easily copy the generated prompt to your clipboard or reset all fields.

Sample Prompt Loader: Includes a built-in example to help beginners understand how it works.

Responsive Design: Looks great on both desktop and mobile screens.

💻 How to Run Locally in VS Code
Clone or Download this repository to your local machine.

Open the folder in Visual Studio Code.

Install the Live Server extension from the VS Code Marketplace (if you haven't already).

Open index.html, right-click anywhere in the editor, and select Open with Live Server.

The application will automatically open in your default browser!
